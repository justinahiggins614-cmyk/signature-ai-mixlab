❓ First-time user guide — what everything does

Forge fresh hybrids. Type a hybrid number (1–1,000,000) and tap Forge — the forge computes 12 hybrids on demand, live in your browser, nothing stored. Surprise me draws a random dozen. ⟳ Regenerate re-forges the same pairs to prove determinism: same pair, same hybrid, every time.

Stored vs on demand. ARCHIVED = the hybrid is stored in the archive (the count at the top of this page, growing with every drip). COMPUTED ON DEMAND = forged live in your browser — identical every time, nothing stored.

Hybrid file (Open file). The full record: mentality, abilities, both parents with links, lineage, forge seed, and a SHA-256 content hash with a Verify Record button. ⚠ Report record problem builds a copy-ready report.

Ask & dial. Ask answers from the hybrid's file only — it never invents. 📞 Dial this hybrid opens a live session with the hybrid in its fused voice.

Compare two hybrids. Two numbers, side by side: parents, variant, seed, mentality.

Browse the forged archive. Search stored hybrids by name or parent; filter pills: All, Logic-led, Soul-led, 50/50, Word-AI parent, System × Persona. The A–Z bar jumps by first letter. Typing a JAH-MIX-###### ID jumps straight to it.

Copy, download, share. Copy the record text, download .txt or .json, or Share a link like ?mix=JAH-MIX-000042 — the link opens the same hybrid on any device, and survives a refresh.

Read aloud. The 🔊 button reads any hybrid file with tiered audio failover.

Site statistics. The top counter shows hybrids stored in the archive (live from the manifest); the second counts hybrids forged on this device only — reset clears it.

The forge is deterministic: hybrid JAH-MIX-###### is always the same fusion of the same two parents, on any device, forever. Seeded hybrids are stored in lazy-loaded chunks; unseeded hybrids compute on demand.
